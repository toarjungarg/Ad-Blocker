Ad-Blocker test page

What you should see

  • Extension on: every row in the first table says blocked, every fake ad box is gone (every row in the second table says hidden), and the real content box is still there.
  • Extension off: the rows say loaded, and all the fake ad boxes show up.
  • You need an internet connection. With no connection, every request fails and looks like it was blocked.
  • After you turn the extension on or off in chrome://extensions, reload this page.
